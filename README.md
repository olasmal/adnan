# Data Analyst / Business Intelligence Portfolio

A responsive, minimalist portfolio website built with plain HTML, CSS and JavaScript. To host on GitHub Pages.

## 1. Personalize before publishing

Open `index.html` and replace these placeholders:

- `Your Name` — your display name and page title.
- `YN` — initials in the logo and favicon (`assets/favicon.svg`).
- `Your City` — optional location.
- `your.email@example.com` — your real contact email.
- `https://www.linkedin.com/` — your LinkedIn profile URL.
- `https://github.com/` — your GitHub profile URL.
- Project repository links — replace each generic GitHub link with the correct project repository.
- About, education and experience copy — make it accurate to your background.

**Important:** The three project cards are starter concepts with illustrative visuals, not completed-work claims. Replace the descriptions, links and visuals with projects you have actually completed. Remove any skill or tool you have not used yet. Do not publish invented metrics or qualifications.

## 2. Add your CV (optional)

1. Export your CV as a PDF.
2. Create a folder named `assets` if it does not already exist.
3. Add the file as `assets/cv.pdf`.
4. In `index.html`, add a link such as:
   `<a href="assets/cv.pdf" download>Download CV</a>`

The starter site does not include a fake CV file.

## 3. Publish free with GitHub Pages

1. Sign in or create a free account at https://github.com/.
2. Create a new **public** repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
3. Upload the contents of this folder to the **root** of that repository. `index.html` must be at the repository root, not inside another nested folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and visit `https://yourusername.github.io/`.

For a repository with a different name, GitHub Pages can also publish at `https://yourusername.github.io/repository-name/` using the same Pages settings.

Official guide: https://docs.github.com/en/pages/quickstart

## 4. Preview locally

You can double-click `index.html` to preview it in a browser. For a local development server, open this folder in VS Code and use the Live Server extension, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/.

## 6. Before sharing with recruiters

- Replace every placeholder and generic link.
- Add 2–3 genuine projects with a clear problem, dataset source, process, findings and limitations.
- Link to readable GitHub repositories or live dashboards.
- Check the site on mobile.
- Confirm your email and social links work.
- Only list skills you can discuss confidently in an interview.
